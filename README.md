# Auspicious24 — Luxury Dry Fruits, Festive Hampers & Designer Apparel Catalog

A modern, mobile-first catalog website for **Auspicious Enterprises (Auspicious24)**, featuring direct WhatsApp ordering & inquiries.

## Features Roadmap
- [x] Product catalog & category filtering (Dry Fruits, Gift Hampers, Designer Suit Fabrics, Festive Essentials)
- [x] WhatsApp order redirect with pre-filled message (Product title, SKU/ID, price, link)
- [x] Responsive, luxury aesthetic (Gold, emerald, deep jewel tones inspired by festive gifting)
- [x] Product quick-view and image galleries
- [ ] Share on WhatsApp / Socials
- [ ] Future phase: Cart, Checkout, Razorpay/Stripe integration

## Tech Stack
- Framework: Next.js (App Router) / React / Tailwind CSS
- Data Source: Shopify JSON sync / local static schema
